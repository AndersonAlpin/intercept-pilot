# InterceptPilot 1.2.4

## Highlights

- Dropdown menus are easier to scan and hover, with spacing between menu items in both Full App and Sidepanel.
- The default collection checkbox tooltip now explains bulk-selection behavior instead of implying only deletion.
- The Sidepanel Rules tab preserves the lower card border treatment used by Network.

## In-App Update Notes

This patch intentionally does not register in-app update notes. Version `1.2.4` is small UI polish, so the Full App `Atualizações` menu remains hidden for this version.

## Fixes

- Added spacing between custom select menu items so adjacent hover states no longer feel glued together.
- Updated the default collection checkbox tooltip from a deletion-specific message to a generic bulk-action selection message.
- Fixed the Sidepanel Rules card footer finish so the lower border remains visible while header dropdowns can still escape the card.

## Scope Notes

This patch release does not change extension permissions, Manifest V3 permission lists, capture runtime behavior, rule engine behavior, hit state logic, rules file organization, MCP/local bridge behavior, Native Messaging, or a local companion app.

## Manual Validation Recommended

- Open collection dropdowns in Full App and Sidepanel, then hover neighboring options and confirm each hover target has visible breathing room.
- Open Full App Collections and hover the disabled checkbox for the default collection. Confirm the tooltip explains that it cannot be selected for bulk actions.
- Open the Sidepanel Rules tab and confirm the lower card border remains visually consistent with the Network tab.
- Open the Sidepanel Rules collection select and Templates menu to confirm they still escape the card without clipping.
- Confirm the Full App `Atualizações` menu stays hidden for version `1.2.4`.

## Validation

- `node --check` on changed JavaScript and locale files.
- Relevant release-notes, collection, rules layout, and Sidepanel layout tests, including the hidden update-menu behavior for `1.2.4`.
- `npm test`.
- `git diff --check`.
- `git diff -- manifest.json package.json package-lock.json` reviewed to confirm the release version bump.
