# InterceptPilot 1.2.1

## Highlights

- The Rules screen keeps actions inside the panel even in larger collections.
- The Rules bulk action bar stays visible without reducing the list area.
- Rules and Collections no longer shift content when opening screens with scroll.

## In-App Update Notes

The in-app update modal for version `1.2.1` reuses the consolidated user-facing copy from `1.2.0` while displaying the current version number.

The Chrome Web Store short release notes remain focused on the patch fixes below.

## Fixes

- Fixed Rules rows whose action buttons could escape the visible panel in narrower Full App widths.
- Fixed the selected-rules bulk action bar so it remains visible without reserving an extra layout band.
- Fixed the opening layout shift in Rules and Collections caused by delayed scrollbar spacing.

## Scope Notes

This patch release does not change extension permissions, Manifest V3 permission lists, capture runtime behavior, rule engine behavior, hit state logic, rules file organization, MCP/local bridge behavior, Native Messaging, or a local companion app.

## Manual Validation Recommended

- Open Rules with a larger collection and confirm row actions stay inside the panel.
- Select rules at the top, middle, and bottom of a larger collection and confirm the bulk action bar remains visible.
- Open Rules and Collections with enough rows to trigger scroll and confirm there is no visible opening shift.
- Confirm PT, EN, and ES update notes show version `1.2.1`.

## Validation

- `node --check` on changed JavaScript and locale files.
- Relevant release notes, layout, and scroll-state tests.
- `npm test`.
- `git diff --check`.
- `git diff -- manifest.json` reviewed to confirm only the version changed.
