# InterceptPilot 1.3.0

## Highlights

- AI Bridge beta connects InterceptPilot to local AI agents.
- Local MCP integration uses a shared daemon so multiple clients/adapters can connect without port conflicts.
- Configurable permissions control which data AI can see and which actions it can run.
- Assisted proposals support imports, rule actions, collection switching, safe edits, protected deletes, and captured-tab reload.
- Search/filter tools and rule-match diagnostics help validate mocked scenarios after changes.

## In-App Update Notes

Version `1.3.0` registers in-app update notes. The Full App `Atualizações` menu should appear for this version with short user-facing AI Bridge/MCP highlights localized in PT, EN, and ES.

## Main Features

- Dedicated AI Bridge page in the Full App.
- Stable connection key for local MCP clients.
- Shared local daemon and MCP adapters for multiple clients.
- Sanitized current test context.
- Reads for captured requests, logs, rules, collections, active collection, and recent rule results.
- Search tools for requests, logs, rules, and rule results.
- Import bundle proposals for rules and collections.
- Assisted rule actions.
- Active collection switching.
- Assisted safe edits for rules and collections.
- Protected rule and collection deletion.
- Captured-tab reload proposals.
- Data and action permissions controlled by the user.

## Security

- Data is sanitized by default.
- Sensitive data is exposed only when the matching AI Bridge permission is enabled.
- Actions can require human confirmation depending on permissions.
- Deletions remain protected by confirmation.
- The stable connection key must not appear in logs, errors, snackbars, or MCP tool returns.
- Local communication uses `127.0.0.1`.

## Scope Notes

- This release does not publish `interceptpilot-mcp` to npm yet.
- Local/dev package configuration may still be required.
- This release does not add direct MCP control of capture or debugger state.
- This release does not add direct `clear_logs`, `set_capture_mode`, or generic reload tools.

## Manual Validation Recommended

- Open the AI Bridge page.
- Start AI Bridge.
- Connect a local MCP client.
- Confirm the shared daemon and one or more adapters can connect.
- Call read-only tools for context, requests, logs, rules, collections, and recent results.
- Test an import proposal.
- Test a rule action proposal.
- Test an assisted edit proposal.
- Test protected delete confirmation.
- Test captured-tab reload proposal.
- Test restricted, assisted, advanced, and custom permissions.
- Disconnect and reconnect the extension, then confirm existing adapters recover.
- Confirm PT, EN, and ES update notes show version `1.3.0`.
