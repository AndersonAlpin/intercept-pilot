# InterceptPilot 1.2.0

## Highlights

- Capture status is more consistent between Full App and Sidepanel.
- Rules are easier to organize, with more room for names/URLs and the option to move selected rules to another collection.
- Network and Logs are more stable during real-time updates.
- Import now accepts dropping JSON files into the editor while preserving manual paste and file selection.
- The interface is clearer and easier to read, with unavailable actions explaining why and more solid toasts.

## Improvements

- Improved capture status consistency between Full App and Sidepanel.
- Disabled `Clear network` and `Clear logs` when the active capture context has no applicable data to clear.
- Disabled invalid import and unchanged settings actions, keeping their unavailable state clear.
- Added localized disabled-state explanations for key actions in PT, EN, and ES.
- Added disabled tooltip support for wrapped button layouts without making the buttons themselves interactive.
- Removed trailing punctuation from short tooltip messages for a cleaner UI tone.
- Rebalanced the Rules grid so rule names and URLs have more room in the Full App.
- Moved Hits closer to rule state and farther from the action buttons.
- Removed noisy tooltips from Hits counters in the Rules list.
- Improved toast contrast with an opaque base surface while preserving success, error, and info variants.
- Reworked Rules, Collections, Network, and Logs list layout so scrollbars belong to the row area instead of the whole panel body.
- Added right-side spacing when table rows have a vertical scrollbar, keeping action columns away from the scrollbar.
- Reworked Sidepanel scrolling so the capture header, tab selector, card header, filters, and footers stay stable while only the active tab list scrolls.
- Simplified the Import screen copy by keeping drag/drop guidance inside the textarea placeholder.
- Added JSON drag-and-drop preparation: dropping one `.json` file fills the textarea and waits for the user to click `Import JSON`.
- Added localized feedback for invalid file type, multiple files, file-read errors, and file-ready state.
- Added Full App update notes backed by the current extension version from `chrome.runtime.getManifest().version`.
- Stored update-note seen state outside user settings, using dedicated storage keys for seen version and seen timestamp.
- Added a sidebar `Updates` item that shows an unread badge until the current version is viewed.
- Kept the `Updates` item visible for three days after reading, then hides it automatically.
- Removed automatic opening of the update-notes modal to avoid interrupting the user on app entry.
- Added a bulk `Move` action for selected rules, using a destination collection selector and preserving rule data.
- Kept rule diagnostics and hit counters with the moved rules so history follows the rule instead of the source collection.
- Aligned the Sidepanel Rules count with the filter area, matching Network and Logs.
- Kept the Sidepanel dense and limited update-note UI to the Full App.
- Improved Network and Logs stability during real-time updates.

## Fixes

- Fixed capture controls that could appear inactive while a Full capture or Light capture tab id was still active.
- Preserved active capture rendering in Full App and Sidepanel when the active tab object is not materialized yet.
- Prevented cleanup buttons from appearing actionable when there is nothing in the current active context.
- Fixed transparent-looking toasts by removing translucent base surfaces.
- Replaced sticky table headers with separated header/body blocks to avoid sticky scrolling artifacts.
- Removed sticky Sidepanel bars that could make content slide behind fixed-looking headers.
- Fixed table action columns and action headers that could sit too close to scrollbars.
- Fixed the Network resource type header appearing as hardcoded `TYPE` in Portuguese.
- Shortened the Network resource type table header to `Tipo`/`Type` to avoid awkward line breaks.
- Fixed the move-rules destination selector being clipped inside the modal body.
- Removed the large update-notes button from Settings after adding the sidebar Updates menu.
- Fixed clicks that could be lost in Network and Logs when live updates replaced list rows between pressing and releasing the mouse.

## Scope Notes

This release does not change extension permissions, Manifest V3 permission lists, capture runtime behavior, rule engine behavior, hit state logic, rules file organization, MCP/local bridge behavior, Native Messaging, or a local companion app.
