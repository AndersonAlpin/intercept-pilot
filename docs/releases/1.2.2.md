# InterceptPilot 1.2.2

## Highlights

- The Sidepanel keeps the current rules list position and lets header menus open outside the Rules card again.

## In-App Update Notes

The in-app update modal for version `1.2.2` uses a patch-specific note covering the Sidepanel Rules regressions introduced by the `1.2.1` layout patch.

## Fixes

- Fixed the Sidepanel Rules list jumping back to the top after toggling a rule on or off.
- Fixed Sidepanel Rules header dropdowns that were opening clipped inside the card container.
- Preserved the current Sidepanel list scroll position across rules, network, and logs rerenders.

## Scope Notes

This patch release does not change extension permissions, Manifest V3 permission lists, capture runtime behavior, rule engine behavior, hit state logic, rules file organization, MCP/local bridge behavior, Native Messaging, or a local companion app.

## Manual Validation Recommended

- Open the Sidepanel Rules tab with enough rules to scroll.
- Scroll the rules list away from the top, enable or disable a rule, and confirm the list stays in place.
- Open the `Templates` menu and the collection select in the Sidepanel Rules header and confirm their lists can escape the card without being clipped.
- Confirm the Sidepanel still updates rule state, hits, and toggle status correctly after the change.
- Confirm PT, EN, and ES update notes show version `1.2.2`.

## Validation

- `node --check` on changed JavaScript and locale files.
- Relevant Sidepanel scroll-state and release-notes tests.
- `npm test`.
- `git diff --check`.
- `git diff -- manifest.json package.json` reviewed to confirm the release version bump.
